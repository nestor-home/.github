# Nestor

An open-source framework for home assistants: a fast voice agent wired to Home Assistant, with
memory, delegation of long tasks, initiative, and any body you give it, from a speaker to a robot.

[nestorhome.dev](https://nestorhome.dev) · [Discussions](https://github.com/orgs/nestor-home/discussions)

| Repository | Package |
|---|---|
| [nestor](https://github.com/nestor-home/nestor) | the server: `pip install nestor-home`, or `ghcr.io/nestor-home/nestor` |
| [nestor-satellite-python](https://github.com/nestor-home/nestor-satellite-python) | `pip install nestor-satellite` |
| [nestor-satellite-typescript](https://github.com/nestor-home/nestor-satellite-typescript) | `npm install @nestor-home/satellite` |
| [nestor-satellite-rust](https://github.com/nestor-home/nestor-satellite-rust) | `cargo add nestor-satellite` |
| [nestor-reachy](https://github.com/nestor-home/nestor-reachy) | Reachy Mini as a satellite: `pip install nestor-reachy` |
| [nestor-web](https://github.com/nestor-home/nestor-web) | the website |

Satellites speak the `nestor.satellite/1` protocol. Every SDK passes the server's conformance suite.
